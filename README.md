# gamesrebirth.github.io

Homepage of Games Rebirth, served by GitHub Pages at
<https://gamesrebirth.github.io>. Every visit opens a toast with the copyright
and trademark notice.

## Quick start

Plain HTML, CSS and JavaScript with no build step. Preview locally with any
static server, for example:

```sh
npx -y serve .
```

Pushing to `main` publishes the site.

The notice text appears in the toast in `index.html` and in
[`COPYRIGHT-NOTICE.md`](https://github.com/gamesrebirth/.github/blob/main/COPYRIGHT-NOTICE.md);
keep the two in step.
